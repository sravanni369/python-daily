8. LEAKAGE CHECK - THE PART THAT DECIDES WHETHER ANY OF THIS IS REAL
==========================================================================
zhvi_3bed and zhvi_1bed are Zillow Home Value Indices for 3-bed and 1-bed
homes. The target is the Zillow Home Value Index for all homes. Those are
the same measurement on a subset of the same houses, so a model leaning on
them is not predicting a price, it is copying one. bed_premium is built from
both, so it goes too. Refit with all three removed.

                                 test RMSE   % of median
with ZHVI-derived features          63,073         24.4%
with them removed                   89,329         34.6%

error grows 42% once the leak is closed
